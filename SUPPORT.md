## 2. Automated Diagnostic CLI

If your local server or extension is failing, run our automated health check in your terminal:

```bash
node health-check.js
```

This will diagnose Node.js compatibility, missing `.env.local` keys, and build artifact status.

## 3. GitHub Issues & Discussions

- **Bug Reports**: Open an issue using our `Bug Report` template. Please attach terminal logs or Chrome DevTools Console screenshots.
- **Feature Requests**: Have an idea for a new zero-click Action Card or platform (e.g., Twitter/X or GitHub PRs)? Submit a `Feature Request` issue!

## 4. Community & Security Contact

- **Security Vulnerabilities**: Report privately to `security@promptless.ai` (See `SECURITY.md`).
- **General Inquiries**: Contact our maintainer team via GitHub Discussions.
